# Repository instructions

When acting on behalf of Etincelles-Inc in this company checkout, use the verified company identity. These instructions do not authorize unrelated contributors to impersonate the company.

- Before each commit, verify both Git author and committer resolve to Etincelles-Inc and the repository-configured company email.
- Publish through the Etincelles-Inc GitHub account.
- Keep Git identity settings repository-local. Do not change the user's global Git identity.
- Do not copy a personal account identity into public commits, documentation, release notes or project metadata.
- Use the existing verified company identity rather than inferring authorship from global Git settings.
